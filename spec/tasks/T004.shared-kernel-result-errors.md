# T004 shared kernel, Result & error mapping
> st:todo | ssot:ARCH-10 ARCH-11 ARCH-12 ARCH-14 ARCH-17 ARCH-20 ARCH-23 | base:ARCH@2 | dep:T003

## goal
Domain building blocks (Entity/VO/DomainEvent/UUIDv7 id), the neverthrow `Result` convention, `DomainError` → HTTP mapping, and dependency-cruiser rules that enforce the Clean layering.

## acceptance
- [ ] `src/shared/kernel`: `ValueObject<T>` (structural equality via `equals`), `Entity<TProps>` (identity equality on `id`), `AggregateRoot` (`pullEvents()` draining a buffer), `DomainEvent` (`name`, `occurredAt`, `aggregateId`), `EntityId` (UUIDv7 generate/parse/validate)
- [ ] `src/shared/result`: `Result<T, E extends DomainError>` alias over neverthrow, `ok`/`err` re-exports, `DomainError` abstract base with readonly `code: string` + `message` + optional `details`, and `NotFoundError` `ConflictError` `ValidationError` `ForbiddenError` `UnauthorizedError` subclasses
- [ ] `src/shared/presentation`: `unwrap(result)` helper that returns the value or throws `DomainHttpException(code,status,message,details)`, plus one `DomainExceptionFilter` rendering `{ code, message, details? }` (ARCH-17) for every error
- [ ] status map is a single explicit table (NotFound→404, Conflict→409, Validation→422, Forbidden→403, Unauthorized→401, default→400); an unmapped/unknown throwable → 500 with code `INTERNAL`, full error logged, message not leaked to the client
- [ ] `.dependency-cruiser.cjs` forbids: `domain` → `application|infrastructure|presentation`, `application` → `infrastructure|presentation`, `domain|application` → `@nestjs/*|drizzle-orm|fastify|pino`, and cross-context deep imports (`src/<a>/**` → `src/<b>/**` other than a context's public module file); runs inside `pnpm turbo run lint`
- [ ] test: kernel unit tests — VO equality by value, Entity equality by id, `pullEvents` empties the buffer, EntityId rejects a non-v7 uuid
- [ ] test: unit tests for every row of the status map + the unknown-error fallback; a contract test asserting the wire shape `{code,message}` for a route that returns `err(new NotFoundError(...))`
- [ ] test: `layering.test.ts` runs dependency-cruiser programmatically over fixture files that violate each rule and asserts each is reported

## impl notes
- neverthrow for `Result` (ARCH-12); `throw` stays for programmer errors only — the filter turning unknown throwables into 500 is the safety net, not a supported path
- `code` values are stable public API (ARCH-17): SCREAMING_SNAKE, prefixed by context once contexts exist (`AUTH_SESSION_EXPIRED`); the base classes carry a generic default code that subclasses in each context override
- UUIDv7: use `uuid` v10+ `v7()` (or `crypto.randomUUID` only where v4 is acceptable — it is not, ARCH-14 says v7) ← time-ordered ids keep PG index locality
- kernel and result live under `src/shared` and import nothing from Nest, so `domain/` may use them freely (ARCH-11)
- validation errors from zod (T006) map onto `ValidationError` with `details` = flattened issues, so web gets field-level messages
