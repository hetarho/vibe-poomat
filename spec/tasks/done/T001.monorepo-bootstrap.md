## goal
Stand up the pnpm/Turborepo workspace with TypeScript, Biome, Vitest and git hooks so every later task has a green verify loop.

## acceptance
- [v] `pnpm-workspace.yaml` declares `apps/*` and `packages/*` and a `catalog:` block pinning shared dep versions (typescript, zod, vitest, @types/node)
- [v] root `package.json`: `"packageManager": "pnpm@10.x"`, `"engines": { "node": ">=22" }`, `private: true`; `.nvmrc` = 22
- [v] `packages/tsconfig` publishes `base.json` (`strict`, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`, `moduleResolution: bundler`, `target: ES2023`), `node.json`, `react.json`; every workspace package extends one of them
- [v] `turbo.json` defines `lint` `typecheck` `test` `build` with `build` depending on `^build` and correct `outputs`; no task uses `cache: false` except `dev`
- [v] `biome.json` at root: formatter + linter on, `noExplicitAny` = error, filename convention kebab-case, import organizing on
- [v] Husky `pre-commit` runs lint-staged → `biome check --staged --write`
- [v] `pnpm turbo run lint typecheck test` exits 0 on a clean checkout; `pnpm biome format --write .` is a no-op afterwards
- [v] test `tooling.test.ts` (root vitest project) asserts the workspace invariants and fails if any is dropped: workspace globs cover `apps/*`+`packages/*`, turbo has the four pipelines, biome has `noExplicitAny: error`, every package's tsconfig extends `@repo/tsconfig`

## impl notes
- versions: pnpm 10, turbo 2.x, typescript 5.x, biome 2.x, vitest 3.x, husky 9, lint-staged 15 — pinned exactly in the root `package.json`, shared ones through the pnpm catalog so no package drifts (ARCH-3)
- package names: `@repo/tsconfig` `@repo/config` `@repo/contracts` `@repo/api-client`; apps are `api` and `web` ← scoped names keep workspace imports unambiguous
- vitest runs as a workspace of projects (root `vitest.config.ts` with `projects`), so a single `pnpm turbo run test` covers unit/int/web; int and e2e projects are added by T005/T007
- `any` needs a `// why:` comment per ARCH-2 — Biome cannot express that, so `noExplicitAny` is a hard error and exceptions use `// biome-ignore lint/suspicious/noExplicitAny: why: ...`
- do NOT create app folders here beyond empty scaffolding; `apps/api` and `apps/web` are owned by T003/T007
- `.gitignore`: `node_modules .turbo dist .env *.local coverage playwright-report test-results`
