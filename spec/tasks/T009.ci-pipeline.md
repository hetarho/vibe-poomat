# T009 CI pipeline
> st:todo | ssot:ARCH-22 ARCH-27 ARCH-28 | base:ARCH@2 | dep:T005 T007

## goal
GitHub Actions PR pipeline running affected lint/typecheck/test/build plus Playwright, with the 80% coverage gate on domain+application.

## acceptance
- [ ] `.github/workflows/ci.yml` on pull_request: checkout with `fetch-depth: 0`, pnpm + Node 22 with store cache, `pnpm turbo run lint typecheck test build --filter=...[origin/main]`
- [ ] a Playwright job (browser binaries cached) running `apps/web` e2e against a built app; report uploaded as an artifact on failure
- [ ] integration tests run in CI: Docker is available on the runner so the Testcontainers harness from T005 works unchanged — no separate PG service definition
- [ ] vitest coverage thresholds: 80% lines enforced on `apps/api/src/*/domain/**` and `apps/api/src/*/application/**` only (ARCH-22); the run fails below threshold
- [ ] PR title validated against Conventional Commits (ARCH-27)
- [ ] `actionlint` runs over `.github/workflows/` as part of `pnpm turbo run lint`
- [ ] this workflow covers PR verification only; the main-branch build/deploy workflow is T016 (ARCH-30 now decided) and must not be duplicated here
- [ ] test: a local `pnpm turbo run test -- --coverage` run fails when a domain file's coverage drops below 80% (verified with a temporary uncovered fixture, reverted after)
- [ ] test: actionlint reports an error on a deliberately broken workflow fixture

## impl notes
- concurrency group per PR with `cancel-in-progress: true` ← superseded pushes should not burn runner minutes
- turbo remote cache is not configured in v1 (no account decision); local cache only
- coverage is measured only where ARCH-22 requires it: adding web/infrastructure to the gate would make the number meaningless and block honest refactors
- the pipeline must stay green with zero bounded contexts present, so the coverage gate skips gracefully when no matching files exist
