# T007 web app skeleton
> st:todo | ssot:ARCH-5 ARCH-6 ARCH-8 ARCH-21 ARCH-22 ARCH-23 ARCH-34 | base:ARCH@2 | dep:T002

## goal
Runnable `apps/web` TanStack Start SSR app with the FSD layout enforced by Steiger, Tailwind v4 + shadcn/ui base, and the unit + e2e test harnesses.

## acceptance
- [ ] `pnpm --filter web dev` serves SSR `/` with a base shell (header with product name + auth slot placeholder, main, footer) and a 404 route; `pnpm --filter web build` produces the production output
- [ ] `src/{app,pages,widgets,features,entities,shared}` exist, each slice exposing `index.ts`; `app/routes/*` files contain routing only and import from `src/pages/*` (ARCH-5)
- [ ] Steiger runs in `pnpm turbo run lint` with the FSD ruleset (public-api, layer-imports, no cross-imports)
- [ ] Tailwind v4 configured CSS-first (`@import "tailwindcss"` + `@theme` tokens) — no `tailwind.config.js` unless a plugin forces it
- [ ] shadcn/ui initialized with `components.json` aliasing to `src/shared/ui`; Button, Input, Textarea, Dialog, Toast generated as the seed set and committed as owned source (ARCH-8)
- [ ] Vitest jsdom project + Testing Library set up for `apps/web`; Playwright config with the dev server webServer hook and `apps/web/e2e/`
- [ ] test: render test of the base shell (header/main/footer present, 404 route renders its message)
- [ ] test: `fsd.test.ts` running Steiger over fixture slices that import upward / bypass `index.ts` and asserting both are reported
- [ ] test: `e2e/smoke.spec.ts` loads `/` and asserts the shell renders server-side (content present with JS disabled)

## impl notes
- TanStack Start with React 19 (ARCH-5); routes are file-based under `app/routes/`, and every route file's body is a thin wrapper over a page component ← keeps Steiger's layer rules meaningful
- no auth-aware UI here: the header shows a placeholder slot that the AUTH tasks fill; do not invent a sign-in button target
- no data fetching in this task — QueryClient/api-client wiring is T008, so the shell renders static content only
- keep the seed shadcn set small; later feature tasks add components as they need them (they are owned source, so each addition is a normal commit)
- Playwright: chromium only in local/PR runs (ARCH-28 runs it on PRs); no visual snapshots in v1
