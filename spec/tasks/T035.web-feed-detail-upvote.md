# T035 web: feed, project detail & upvote
> st:todo | ssot:PROJ-9 PROJ-10 PROJ-11 PROJ-1 ARCH-6 ARCH-7 | base:PROJ@2 ARCH@2 | dep:T032 T024

## goal
The landing feed with tag filter, the popular tab, and the project detail page with upvoting.

## acceptance
- [ ] `/` renders the default feed (projects with open slots first, then newest — PROJ-9) as cards: cover, title, pitch, tags, owner, upvote count, claimable-slot badge; infinite scroll on the cursor
- [ ] tag filter chips update the URL query and the SSR loader honours it on a cold load
- [ ] `/popular` renders the 7-day ranking (PROJ-10) with the same card component
- [ ] `/projects/$id` renders the full project (description markdown, live URL as a prominent external link with `rel="noopener noreferrer"`), the owner block, the active mission summary, and the public feedback list
- [ ] upvote button toggles optimistically with rollback on error; hidden (not merely disabled) on your own project; a signed-out click opens the sign-in dialog with `returnTo` (PROJ-11)
- [ ] a soft-deleted project renders 404 for visitors and an "archived" banner for its owner (PROJ-8)
- [ ] empty states for both tabs and for a project with no feedback yet
- [ ] test: render tests — card shows the slot badge only when slots are claimable; own-project card hides the upvote control
- [ ] test: optimistic upvote increments then rolls back on a failed mutation; the count matches the server value afterwards
- [ ] test: signed-out upvote opens the sign-in dialog and does not call the API
- [ ] test: tag filter reflects into the URL and back on reload

## impl notes
- FSD: `pages/feed`, `pages/popular`, `pages/project-detail` over `widgets/project-card`, `features/upvote-project`, `entities/project` — the card widget is shared by all three so ranking changes never fork the markup
- infinite scroll uses `useInfiniteQuery` with the opaque cursor from T024; page state stays in the query cache, not Zustand (ARCH-7)
- the live URL opens in a new tab: the whole point of PROJ-2 is that a feedbacker can actually use the thing
